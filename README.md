# 은행 마케팅 캠페인 분석

## 프로젝트 개요
은행 전화 마케팅 캠페인 데이터를 기반으로
정기예금 가입 가능성이 높은 고객군을 분석하고
타겟 마케팅 전략을 도출한 프로젝트입니다.

## 사용 기술
- Python (Pandas, Matplotlib, Seaborn, Scipy)
- Jupyter Notebook

## 노트북 구성
| 번호 | 파일명 | 내용 |
|------|--------|------|
| 01 | data_cleaning | 데이터 전처리 및 파생변수 생성 |
| 02 | analysis | 가입률 분석 및 시각화 |
| 03 | insight_action | 핵심 인사이트 및 타겟 마케팅 전략 |

## 핵심 분석 결과
- 60세 이상 (주택대출X) 가입률 42.3% (전체 평균 15.5%의 2.7배)
- 5~8월 성공률 10% 초반대 → 비수기
- 통화 11분 이상 성공률 63.6%로 역전
- 연락 횟수 3회 이내가 가장 효율적
