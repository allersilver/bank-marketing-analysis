# Bank Marketing Campaign Analysis
## 데이터 기반 타겟 고객 세그먼트 설계 프로젝트

---
> **Note**
> 본 레포지토리는 데브코스 팀 프로젝트를 기반으로, 개인적으로 분석을 재구현한 코드입니다.
> 원본 팀 프로젝트의 분석 방향과 결과를 참고하여 직접 작성하였습니다.

---

## 프로젝트 배경

은행의 전화 마케팅 캠페인은 무작위 대상에게 전화를 걸어 정기예금 가입을 유도하는 방식으로 운영됩니다.
그러나 **전체 평균 가입률은 15.5%에 불과**하며, 나머지 84.5%는 비용만 발생하는 비효율 구간입니다.

> **"누구에게, 언제, 몇 번 전화해야 가입률을 높일 수 있을까?"**

이 질문에서 분석이 시작되었습니다.

---

## 분석 목적

- 정기예금 가입 가능성이 높은 **핵심 타겟 고객군 정의**
- 마케팅 효율을 낮추는 **비효율 타겟 제거 전략 도출**
- 최적 연락 시기·횟수 등 **캠페인 운영 전략 수립**

## 분석 흐름

문제 정의 → 데이터 전처리 → 가설 수립 → 카이제곱·t-검정 → 인사이트 도출 → 전략 제안

### 분석 가설

| 가설 | 검증 방법 |
|------|-----------|
| 연령대에 따라 가입률이 다를 것이다 | 카이제곱 검정 |
| 주택대출 유무가 가입률에 영향을 줄 것이다 | 카이제곱 검정 |
| 통화 시간이 길수록 가입률이 높을 것이다 | t-검정 |
| 계절(월)에 따라 마케팅 성공률이 다를 것이다 | 카이제곱 검정 |

## 핵심 분석 결과

### 타겟 고객군 — 가입률 상위

| 고객군 | 가입률 | 전체 평균 대비 |
|--------|--------|----------------|
| 60세 이상 (주택대출 없음) | 42.3% | 2.7배 |
| 학생 | 35.4% | 2.3배 |
| 은퇴자 (대출 없음) | 30.6% | 2.0배 |
| 29세 이하 (개인대출 없음) | 25.0% | 1.6배 |

### 비효율 타겟 — 제거 권장

| 고객군 | 특징 |
|--------|------|
| 기혼 + 주택·개인대출 보유 | 전 조합 가입률 하위권 |
| 자영업 + 저소득층 | 반응률 낮음 |
| 신용 불량 고객 | 전 조합 최하위 |

### 캠페인 운영 전략

| 항목 | 권장 사항 |
|------|-----------|
| 집중 시기 | 3월, 9~12월 (성공률 50% 이상) |
| 최소화 시기 | 5~8월 (성공률 11.7%) |
| 최적 연락 횟수 | 3회 이내 |
| 통화 목표 시간 | 11분 이상 (성공률 63.6% 역전) |

## 한계점 및 개선 방향

- 통화 시간과 가입률의 인과관계 방향 불명확 (길어서 설득된 것인지 vs 관심 있어서 오래 통화한 것인지)
- 실제 캠페인 비용 데이터 부재로 ROI 계산 불가
- 5~8월 데이터 집중으로 계절별 비교 신뢰도 제한
