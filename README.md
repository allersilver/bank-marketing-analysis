# Bank Marketing Campaign Analysis
## 데이터 기반 타겟 고객 세그먼트 설계 프로젝트

---

## 프로젝트 개요
은행 전화 마케팅 캠페인 데이터를 기반으로
정기예금 가입 가능성이 높은 고객군을 분석하고
**데이터 기반 타겟 마케팅 전략**을 도출한 프로젝트

무작위 전화 방식의 낮은 성과를 데이터로 개선하는 것이 목표.

---

## 기술 스택
- Python (Pandas, Matplotlib, Seaborn, Scipy)
- Jupyter Notebook

---

## 노트북 구성
| 번호 | 파일명 | 내용 |
|------|--------|------|
| 01 | data_cleaning | 데이터 전처리 및 파생변수 생성 |
| 02 | analysis | 가입률 분석 및 시각화 |
| 03 | insight_action | 핵심 인사이트 및 타겟 마케팅 전략 |

---

## 핵심 분석 결과
- 60세 이상 (주택대출X) 가입률 **42.3%** (전체 평균 15.5%의 2.7배)
- 학생 그룹 가입률 **35.4%** → 2순위 타겟
- 5~8월 성공률 **11.7%** → 비수기, 하반기 집중 권장
- 통화 11분 이상 성공률 **63.6%** 로 역전
- 연락 횟수 **3회 이내**가 가장 효율적

## 데이터 한계
- 실제 캠페인 비용 데이터 없어 ROI 계산 불가
- 통화 길이 인과관계 불명확 (통화 길이 → 가입? or 관심 → 통화 길어짐?)
- 특정 시기 데이터 편중으로 월별 분석 신뢰도 제한
